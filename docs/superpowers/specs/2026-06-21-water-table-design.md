# 水位・水圧対応 設計書

作成日: 2026-06-21
対象: 既存「試行楔法による土圧計算ウォーク」への機能追加

## 1. 目的

裏込めに地下水位がある場合の土圧を扱えるようにする。土工指針でも一般的な
**簡易有効応力法**（静水状態を仮定し、水位以下は水中単位体積重量を用い、壁には
別途静水圧を作用させる）を採用し、初学者が「有効土圧 P′」と「水圧 Pw」を分けて
理解できるようにする。Hw=0（無水）で現状と完全一致させる。

## 2. 方式（簡易有効応力法・静水状態）

- 水位以下の土は水中（有効）単位体積重量 γ′ = γ − γw を用いる。
- これで試行楔法から**有効主働土圧 P′** を求める（力の多角形は現状のまま、
  自重 W を有効自重 W_eff に置換するだけ）。
- 壁には別途**静水圧** Pw = ½·γw·Hw²（三角形分布・水平・下端から Hw/3）が作用。
- **全水平土圧 = P′の水平成分 + Pw**。
- 前提: 静水状態（水位は水平、浸透流なし）。すべり面の間隙水圧は有効重量に含めて
  簡易に扱う（標準的な近似）。

## 3. 入力（2つ追加）

- `Hw` = 地下水位の高さ（壁下端からの高さ, m）、範囲 0〜H、初期値 0
- `γw` = 水の単位体積重量（kN/m³）、初期値 9.8

Hw=0 で A_below=0・W_eff=γA・Pw=0 となり、既存挙動に一致。

## 4. 幾何の一般化（`geometry(p, omega)`）

水位線 y=Hw 以下のくさび面積 `Aw`（= A_below）を返す。

- 水位線は壁面 O-T と すべり面 O-B を切り、O とで三角形を作る。
- `Aw = 0.5 · Hw² · |tanθ − cotω|`、ここで cotω = 1/tanω。
- β に依存しない（すべり面の向きは ω のみで決まるため）。
- Hw は内部で `min(p.Hw||0, H)` にクランプ。
- 戻り値に `Aw` を追加（他は不変: `valid, O, T, B, xT, xB, yB, A, L`）。

### 一致確認
- Hw=0 → Aw=0。
- Hw=H, θ=0, β=0 → Aw=½H²cotω = ½H²/tanω = A（全面積）。

## 5. 力の一般化（`solveWedge(p, omega)`）

- 有効自重 `W_eff = γ·g.A − γw·g.Aw`
- `V = W_eff + Q`、Q = q·(xB − xT)（上載は水位上、不変）
- C・R・P の向き・つり合いの解法は**完全に現状のまま**（V のみ W_eff ベースに）
- 静水圧 `Pw = 0.5·γw·Hw²`（Hw=min(p.Hw||0, H)）を計算して返す
- 戻り値に `Aw`（=g.Aw）、`Weff`（=W_eff）、`Pw` を追加（既存キー W は総自重 γ·A のまま残し、解説で W_eff と対比できるようにする）

### 一致確認
Hw=0 → Aw=0 → W_eff=γA（現行 W と同一）、Pw=0。既存の P 計算に一致。

## 6. 試行と合計（`sweep` は不変）

- Pw は ω に依存しないため、`sweep` は従来どおり有効土圧 P′ を最大化する（変更なし）。
- 全水平土圧は UI 側で算出: 臨界 ω の `solveWedge` を呼び、その P ベクトルの水平成分
  `P′_h`（= vectors の P.fx）と `Pw` を足す:
  **全水平土圧 = P′_h + Pw**。

## 7. UI（`index.html`）

- 入力欄に `地下水位 Hw (m)`（id=`Hw`, value=0, step=0.5, min=0）と
  `水の単位体積重量 γw (kN/m³)`（id=`gammaw`, value=9.8, step=0.1, min=0）を追加
- `ids`・`params()` に `Hw`・`gammaw` を追加（params のキーは `Hw`, `gammaw`）
- `validate(p)` に追加:
  - `p.Hw < 0 || p.Hw > p.H` → 「地下水位 Hw は 0〜H(壁高) の範囲で。」
  - `p.gammaw < 0` → 「水の単位体積重量 γw は 0 以上で。」
- ステップ解説（`render.js` の `explain`）に水関連を追記:
  - 自重ステップを「総自重 γ·A から水位以下の浮力を引いた**有効自重 W_eff**」に
  - 新ステップ「**静水圧 Pw = ½γw·Hw²**（下端から Hw/3）」
  - 「**全水平土圧 = P′の水平成分 + Pw**」を末尾に表示
  - Hw=0 のときは水関連の行を出さない（現状の見た目を維持）

## 8. 描画（`render.js`）

- `drawSection` に**水位線**を追加: y=Hw の水平線（水色 `#1e88e5`、細線）を
  くさび内（x: 0〜B.x 相当）に引き、`地下水位` ラベルを付す。Hw=0 のときは描かない。
- 力の多角形・P–ω曲線は構造変更なし（V が W_eff になるだけで自動反映）。

## 9. 検証

- **後退なし**: Hw=0 で既存20テストが全パス（Aw=0, W_eff=γA, Pw=0）。
- **完全水没の理論一致**: Hw=H, θ=0, c=0, δ=0, β=0 で
  - 有効主働土圧 P′ = ½·γ′·H²·Ka（γ′=γ−γw, Ka=1/3）
  - 静水圧 Pw = ½·γw·H²
  を新テストで確認（試行楔法スイープの Pa が ½γ′H²Ka に一致、Pw が解析値に一致）。
- **部分水没の妥当性**: Hw を上げると P′（有効土圧）は減り、Pw は増える。
- **ブラウザ実証**: Hw>0 で水位線が描かれ、解説に W_eff・Pw・全土圧が出る。
  Hw=0 に戻すと水関連表示が消え現状どおり。Playwright で確認。

## 10. スコープ外（YAGNI）

- 浸透流・流線網（定常浸透）による間隙水圧分布
- すべり面の間隙水圧 U を力の多角形に明示する厳密法
- 水位が地表面より上（湛水）／壁前面の水位
- 受働土圧・地震時土圧
