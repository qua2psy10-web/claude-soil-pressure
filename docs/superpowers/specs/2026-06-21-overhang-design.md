# オーバーハング（負の壁背面傾斜）対応 設計書

作成日: 2026-06-21
対象: 既存「試行楔法による土圧計算ウォーク」への機能追加（傾斜壁対応の拡張）

## 1. 目的

壁背面傾斜角 θ を負方向（オーバーハング＝壁天端が裏込めと反対側に倒れる）にも
広げ、より幅広い壁形状を扱えるようにする。

## 2. 重要な前提（検証済み）

計算コア `calc.js`（`geometry`/`solveWedge`/`coulombKa`）は既に θ の符号に依らず
一般化されており、**負の θ をそのまま正しく計算できる**。数値確認済み:

| θ (°) | 試行楔法スイープ Pₐ | Coulomb理論 ½γH²·Ka(φ,δ,β,−θ) |
|---|---|---|
| −15 | 95.42 | 95.42 |
| −10 | 85.14 | 85.14 |
| −5  | 76.02 | 76.02 |
| 0   | 67.82 | 67.82 |
| +10 | 53.36 | 53.36 |
（H=5, γ=18, φ=30, δ=15, c=0, q=0, β=0）

物理的にもオーバーハング（θ<0）ほど Pₐ が増える（妥当）。
したがって **calc.js の数式変更は不要**。

## 3. 角度の定義（符号規約・既存どおり）

- θ = 壁背面の鉛直からの傾斜角（度）
- θ>0 = 壁天端が裏込め（土）側に倒れる（たぶん）
- **θ<0 = 壁天端が土と反対側に倒れる（オーバーハング）**、xT = H·tanθ < 0
- 範囲: **−25° 〜 +25°**（傾斜側と対称）、初期値 0

## 4. 変更点

### 4.1 UI（`index.html`）
- θ入力の `min="0"` を `min="-25"` に変更（`max="25"` は据え置き）
- ラベルに補足: `壁背面傾斜 θ (°)（負=オーバーハング）`
- バリデーション `validate(p)` の範囲を `−25 〜 25` に変更:
  現行 `if (p.theta < 0 || p.theta > 25)` → `if (p.theta < -25 || p.theta > 25)`
  メッセージも「壁背面傾斜 θ は −25〜25° の範囲で。」に更新
- `tanθ·tanβ ≥ 1` の幾何ガードは据え置き（θ<0 では負値となり発火せず、無害）

### 4.2 描画（`render.js` の `makeMap`）
オーバーハングでは xT<0 となり、現行の `X = pad + x·s`（x≥0前提）だと壁天端が
パネル左外にはみ出す。x方向の描画域を `[xmin, xmax]` でマッピングするよう一般化する。

現行:
```js
const xs = [0, geom.T.x, geom.B.x], ys = [0, geom.T.y, geom.B.y];
const xmax = Math.max(...xs) * 1.15 || 1;
const ymax = Math.max(...ys) * 1.15 || 1;
const sx = (vb.width - 2 * pad) / xmax;
const sy = (vb.height - 2 * pad) / ymax;
const s = Math.min(sx, sy);
return (x, y) => ({ X: pad + x * s, Y: vb.height - pad - y * s });
```
変更後（xmin/ymin を考慮。θ≥0 では xmin=0 となり実質現状どおり）:
```js
const xs = [0, geom.T.x, geom.B.x], ys = [0, geom.T.y, geom.B.y];
const xmin = Math.min(...xs), xmax = Math.max(...xs);
const ymin = Math.min(...ys), ymax = Math.max(...ys);
const xspan = (xmax - xmin) * 1.1 || 1;
const yspan = (ymax - ymin) * 1.1 || 1;
const s = Math.min((vb.width - 2 * pad) / xspan, (vb.height - 2 * pad) / yspan);
return (x, y) => ({ X: pad + (x - xmin) * s, Y: vb.height - pad - (y - ymin) * s });
```
力の多角形・P–ω曲線・解説は無変更（`makeMap` は断面図のみが使用）。

## 5. 検証

- **後退なし**: θ≥0 のケースで既存17テストが全パス（calc無変更なので自明だが念のため）。
- **オーバーハング理論一致**: θ=−10 のスイープ最大 Pₐ が `½γH²·coulombKa(φ,δ,β,−θ)`
  （=coulombKa(...,+10)）と 1%以内一致する新テストを追加。
- **単調性**: オーバーハング（θ<0）で Pₐ が θ=0 より増えることを確認。
- **ブラウザ実証**: θ=−15 で断面図の壁天端が左（オーバーハング側）に倒れ、図全体が
  パネル内に収まり、4ペインが連動することを Playwright で確認。

## 6. スコープ外（YAGNI）

- |θ|>25° の極端な形状
- 折れ面の壁背面、受働土圧、水位、地震時土圧（引き続き対象外）
