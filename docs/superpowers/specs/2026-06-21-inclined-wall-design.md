# 傾斜壁（壁背面傾斜）対応 設計書

作成日: 2026-06-21
対象: 既存「試行楔法による土圧計算ウォーク」への機能追加

## 1. 目的

試行楔法の土圧計算アプリは現在、壁背面が鉛直のケースのみを扱う。
これを **壁背面が傾斜したケース** にも対応させ、より実際の擁壁に近い条件で
学べるようにする。θ=0（鉛直）では現行動作と完全に一致させ、後退を出さない。

## 2. 角度の定義（符号規約）

- `θ` = 壁背面の鉛直からの傾斜角（度）
- **正の向き = 壁天端が裏込め（土）側に倒れる向き**（たぶんのついた壁背面）
- 初期値 0（鉛直）、入力範囲 0〜25°（負は扱わない）

座標系は既存どおり: x=水平（右=裏込め側が正）、y=鉛直上向き、壁かかと O=(0,0)。
θ>0 のとき壁天端 T は +x 側に寄る: `T = (H·tanθ, H)`、xT = H·tanθ ≥ 0。

## 3. 幾何の一般化（`geometry(p, omega)`）

入力 `p` に `theta`（度）を追加。

- 壁天端: `xT = H·tanθ`、`T = { x: xT, y: H }`
- すべり面と地表の交点 B:
  `xB = H·(1 − tanθ·tanβ) / (tanω − tanβ)`、`yB = xB·tanω`、`B = { x: xB, y: yB }`
- くさび面積（三角形 O,T,B の一般式）: `A = 0.5·|xT·yB − xB·H|`
- すべり面長: `L = xB / cosω`（不変）
- 有効条件: `β < ω < λ` かつ `xB > 0` かつ `xB > xT`。
  ここで `λ = atan2(H, xT)` を度に変換した値（壁面の傾き角）。
  θ=0 のとき xT=0 → λ=90° となり、現行の `β < ω < 90` に一致する。
- 戻り値に `xT` を追加（描画で利用）。それ以外の形（`valid, O, T, B, xB, yB, A, L`）は維持。

### θ=0 での一致確認
xT=0 → xB = H/(tanω−tanβ)、A = 0.5·xB·H、λ=90° となり現行の `geometry` と同一。

## 4. 力の一般化（`solveWedge(p, omega)`）

くさびに作用する4力。V・C・R は現行どおり、**P の向きのみ一般化**する。

- 自重 `W = γ·A`、上載荷重 `Q = q·(xB − xT)`（地表の水平載荷幅）、`V = W + Q`、向き鉛直下 `(0, −V)`
- 粘着力 `C = c·L`、向き角 `ω`: `C·(cosω, sinω)`（不変）
- 反力 `R`、向き角 `rAng = ω + 90 − φ`（不変、大きさ未知）
- 土圧 `P`、向き角 `pAng = n + δ`、大きさ未知。
  壁面法線角 `n = atan2(−xT, H)` を度に変換した値。
  θ=0 のとき n=0 → `pAng = δ` となり現行に一致。

つり合い（ΣFx=0, ΣFy=0）の連立2元1次（未知数 P, R）はクラメルで解く。
構造は現行と同一で、P の方向角を `δ` から `pAng` に差し替えるだけ:
```
P·cos(pAng) + R·cos(rAng) = −C·cosω
P·sin(pAng) + R·sin(rAng) =  V − C·sinω
```
`vectors` 配列（V, C, R, P の {label, fx, fy}）も pAng を用いて生成。

### θ=0 での一致確認
n=0, pAng=δ, Q=q·xB となり、現行 `solveWedge` と完全一致。

## 5. UI（`index.html`）

- 入力欄に `壁背面傾斜 θ (°)` を追加（id=`theta`, value=0, step=1, min=0, max=25）
- `ids` 配列・`params()` に `theta` を追加
- バリデーション `validate(p)` に追加:
  - `θ` が 0〜25° の範囲外 → 注意
  - `tanθ·tanβ ≥ 1` → 「θ と β の組み合わせが幾何的に成立しません」
  - 有効ω範囲が成立しない（λ ≤ β）→ 注意
- ステッパー文言は変更不要（θは補助パラメータ）

## 6. 描画（`render.js`）

- `drawSection` は `geom.T`（=(xT,H)）を使って壁背面を描くため、傾斜は自動で反映される。
- `makeMap` の x範囲に `geom.T.x` を含める（現状 `xs=[0, geom.B.x]`）。
  → `xs=[0, geom.T.x, geom.B.x]` に修正（xT を描画域に確実に含めるため）。
- 力の多角形・P–ω曲線・解説パネルは無変更（解説は既存の値表示で θ 反映済みの数値が出る）。

## 7. 検証

- **後退なし**: θ=0 で既存10テストが全てパス（不変）。
- **傾斜壁の理論一致**: θ>0 のケースで、試行楔法スイープの最大 Pₐ を
  **Coulomb 主働土圧の一般式** `Pa = ½γH²·Ka` と突き合わせる新テストを追加。
  Ka はクーロン一般式:
  ```
  Ka = cos²(φ−θ) /
       [ cos²θ·cos(δ+θ)·( 1 + sqrt( sin(φ+δ)·sin(φ−β) /
                                     (cos(δ+θ)·cos(θ−β)) ) )² ]
  ```
  符号規約（θの向き）は、θ=0 で現行一致することを起点に、実装時に
  θ=10° 等で数値突き合わせを行い、一致する符号を確定する。許容差は 1%程度。
- **単調性**: θ を増やすと Pₐ が想定方向に変化することを確認（物理的妥当性）。
- ブラウザ実証: θ を入れると断面図の壁背面が斜めになり、4ペインが連動することを Playwright で確認。

## 8. スコープ外（YAGNI）

- 負の θ（オーバーハング側）は扱わない
- 受働土圧・水位・地震時土圧は引き続き対象外
- 折れ面（複数勾配）の壁背面は扱わない（単一傾斜のみ）
