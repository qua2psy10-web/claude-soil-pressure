# 試行楔法による土圧計算 学習アプリ 設計書

作成日: 2026-06-21

## 1. 目的

土工指針の「試行楔法（試行くさび法）」による**主働土圧**の計算過程を、土木の初学者が
手を動かしながら理解できる、対話型の学習アプリを作る。

ユーザーが土の条件を入力し、くさび角 ω をスライダーで動かしながら、土圧 P が
求まる過程をステップごとに目で追える。最後に「最大値を自動探索」して主働土圧 Pₐ を
確定する。

## 2. スコープ

### 含むもの
- 主働土圧の試行楔法による算定
- 砂質土（c=0）と粘性土（c>0）の両方（**粘着力 c を扱う**）
- 入力パラメータ: 壁高 H、単位体積重量 γ、内部摩擦角 φ、壁面摩擦角 δ、粘着力 c、
  上載荷重 q、裏込め勾配 β、壁背面傾斜
- 「手動探索 → 自動確定」の2段階で試行を見せる
- 力の多角形（つり合い）の図解
- P–ω 曲線の表示
- 土圧の作用位置（下端から H/3）・合力の向き

### 含まないもの（YAGNI）
- 受働土圧
- 水位・水圧
- 地震時土圧（物部・岡部など）
- 壁体の安定計算（滑動・転倒・支持力）

初期値の前提:
- 壁背面=鉛直、地表=水平（β・壁傾斜は入力で変更可。v1 は鉛直・水平を主とする）
- UI は日本語のみ
- 土圧分布は三角形分布、作用点=下端から H/3
- 単位は kN, m, kN/m³, 度

## 3. 形態 / 技術スタック

- ブラウザで開く **1ファイル HTML**（HTML + CSS + 素の JavaScript）
- ビルド不要、ダブルクリックで開ける、配布も簡単
- 図解は SVG で描画
- 外部ライブラリ依存なし（グラフも自前 SVG で描く）

## 4. 画面構成

4ペイン連動 + ステップ解説パネル。

| ペイン | 内容 |
|---|---|
| ① 入力 | H, γ, φ, δ, c, 上載荷重 q, 裏込め勾配 β, 壁背面傾斜。数値入力＋スライダー |
| ② 断面図 (SVG) | 擁壁と、現在の ω のくさび・すべり面をリアルタイム描画 |
| ③ 力の多角形 (SVG) | W・C・R・P が閉じる多角形を現在の ω で描画 |
| ④ P–ω 曲線 (SVG) | 各 ω での P をプロット、現在点をハイライト、最大点をマーク |

下部に**ステップ解説パネル**: 現在の ω について「幾何 → 自重 W → 粘着力 C →
力のつり合い → P」を、式に数値を代入した形で日本語表示。

## 5. 学習の流れ（ガイド付きステッパー）

1. 問題設定 — 何を求めるのか（主働土圧）を提示
2. ある ω のくさびを仮定（スライダー登場）
3. くさびの自重 W を計算（面積 × γ ＋ 上載荷重）
4. すべり面の粘着力 C = c · L
5. 力のつり合い（力の多角形）から P を解く
6. ω を変えて繰り返す → P–ω 曲線ができる
7. **最大の P が主働土圧 Pₐ**、その面が臨界すべり面
8. 土圧の作用位置（下端から H/3）・合力の向き δ

初回はこのステッパーで誘導。以降は自由に触れる。

## 6. 計算の中身（力学）

### くさびにかかる4つの力

くさび（壁背面とすべり面に挟まれた土塊）のつり合いを考える。

- **W** — くさびの自重（＋上載荷重 q）。向き=鉛直下向き、大きさ既知
- **C** — すべり面の粘着力 = c × L（L=すべり面長さ）。向き=すべり面に沿う、大きさ既知
- **R** — すべり面の反力。向き=すべり面の法線から φ だけ傾く（摩擦が完全発揮）、**大きさ未知**
- **P** — 壁がくさびを押し返す力。向き=壁背面法線から δ だけ傾く、**大きさ未知**

未知数は P と R の2つ、つり合い式は水平・鉛直の2本。
→ **連立2元1次方程式で一意に解ける**。
これを「力の多角形が閉じる」として図で見せる（初学者に一番効く部分）。

### 試行（最大値探索）

ω を範囲内（裏込め勾配 〜 90°）でスイープし、P(ω) の配列を作る。
**最大値が主働土圧 Pₐ**、その時の ω が臨界すべり面角。

手動探索: ユーザーがスライダーで ω を動かし、P の増減を体感。
自動確定: 「最大値を自動で探す」ボタンで全 ω をスイープ、最大点へアニメーションし、
結果（Pₐ、臨界 ω、作用位置）を確定表示。

### 計算手順（1つの ω について）

1. 幾何: 壁背面・すべり面・地表で囲まれるくさびの頂点を求め、すべり面長 L と面積 A を算出
2. 自重: W = γ · A ＋ (上載荷重 q × 地表での載荷幅)
3. 粘着力: C = c · L
4. つり合い: P と R の方向ベクトルを立て、水平・鉛直の2式から P, R の大きさを解く
5. P が負なら 0 にクランプ（土圧なし）

## 7. 実装構成（1ファイル内、責務分離）

純粋計算関数を UI から切り離す。

- `geometry(inputs, ω)` → くさび頂点・すべり面長 L・面積 A
- `forces(geom, soil)` → W, C を出し、力のつり合いを解いて P, R を返す
- `sweep(inputs)` → ω 総当たり → P(ω) 配列・最大点（Pₐ, 臨界 ω）
- 描画3種: `drawSection()` / `drawForcePolygon()` / `drawPOmegaCurve()`
- `explain(geom, forces)` → ステップ解説テキスト生成

### データフロー
入力 or ω が変化 → 上流（geometry → forces）から再計算 → 全ペイン再描画。
一方向データフロー（状態は単一の `state` オブジェクトに集約）。

## 8. 検証方法

純粋計算関数（geometry / forces / sweep）は UI から独立しているのでテスト可能。
**理論値との突き合わせ**で正しさを担保する。

- **c=0, δ=0, β=0, 鉛直壁** のとき、試行楔法の最大 P は **Rankine の主働土圧**
  Pₐ = ½ γ H² Kₐ（Kₐ = tan²(45°−φ/2)）に一致するはず
  → 自動チェック（例: φ=30° で Kₐ=1/3）
- **臨界すべり面角** が理論値 45°+φ/2 に一致するか
- 粘着力 c を入れたとき P が減る方向に動くか（物理的妥当性）

ブラウザ内に小さなセルフテスト表示（コンソール出力 or 隠しパネル）を置き、
開発時に確認できるようにする。

## 9. エラー処理

- φ < 0、γ ≤ 0 などの不正入力 → 日本語でやさしく注意表示
- ω が幾何的に不成立（すべり面が地表と交わらない等） → その ω を無効扱い
- P が負 → 0 にクランプ（土圧が発生しない条件）
- 入力欄は範囲チェック付き、想定外でもクラッシュしない
