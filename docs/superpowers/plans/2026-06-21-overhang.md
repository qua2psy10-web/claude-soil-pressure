# オーバーハング（負の壁背面傾斜）対応 実装プラン

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 壁背面傾斜角 θ を負方向（オーバーハング）にも拡張し、−25〜25° の壁形状を扱えるようにする。

**Architecture:** 計算コア `calc.js` は既に θ の符号に依らず正しく計算できる（数値検証済み）ため変更しない。負の θ を「特性化テスト」で固定し、UI の入力レンジ／バリデーションを拡張し、`render.js` の `makeMap` を負の xT に対応させる。

**Tech Stack:** 素のHTML/CSS/JavaScript、SVG、`node:test`。外部依存なし。

---

## 前提（検証済み・全タスク共通）

- θ<0 = オーバーハング（壁天端が土と反対側へ倒れる）、xT = H·tanθ < 0。
- `calc.js` は無変更で負θに対応。検証: θ=−10 → スイープ Pₐ=85.14 = ½γH²·coulombKa(30,15,0,+10)。
- 検証式は全θ共通で `theory = ½γH²·coulombKa(φ,δ,β,−θ)`（本アプリθ(+)=Das(−θ)）。
- オーバーハングほど Pₐ は増える（θ=−10:85.14 > θ=0:67.82）。

test('オーバーハング: θ=-10 のスイープ最大が Coulomb 一般式と一致', () => {
  const p = { H: 5, gamma: 18, phi: 30, delta: 15, c: 0, q: 0, beta: 0, theta: -10 };
  const s = TW.sweep(p, { step: 0.05 });

  const p0 = { H: 5, gamma: 18, phi: 30, delta: 15, c: 0, q: 0, beta: 0, theta: 0 };
  const pNeg = { ...p0, theta: -10 };
  assert.ok(TW.sweep(pNeg, { step: 0.1 }).Pa > TW.sweep(p0, { step: 0.1 }).Pa);

test('オーバーハング: θ=-15 で xT が負（壁天端が土と反対側）', () => {

  assert.ok(g.valid);
  assert.ok(g.xT < 0, `xT=${g.xT}`);
  assert.ok(Math.abs(g.xT - 5 * Math.tan(-15 * Math.PI / 180)) < 1e-9);

## Task 3: render.js の makeMap を負の xT に対応

**Files:** Modify `render.js`

- [ ] **Step 1: makeMap を一般化** — `render.js` の `makeMap` 関数の本体を次に置き換える（関数シグネチャ `function makeMap(svg, geom, pad)` は維持）:
```js
  function makeMap(svg, geom, pad) {
    const vb = svg.viewBox.baseVal;
    const xs = [0, geom.T.x, geom.B.x], ys = [0, geom.T.y, geom.B.y];
    const xmin = Math.min(...xs), xmax = Math.max(...xs);
    const ymin = Math.min(...ys), ymax = Math.max(...ys);
    const xspan = (xmax - xmin) * 1.1 || 1;
    const yspan = (ymax - ymin) * 1.1 || 1;
    const s = Math.min((vb.width - 2 * pad) / xspan, (vb.height - 2 * pad) / yspan);
    return (x, y) => ({ X: pad + (x - xmin) * s, Y: vb.height - pad - (y - ymin) * s });
  }
```
（θ≥0 では xmin=0・ymin=0 となり実質現状どおり。θ<0 では xmin<0 を考慮して左へはみ出さない。）
